# age test vectors

Byte-exact copies of the uncompressed X25519, stanza, stream, HMAC and header
vectors from the C2SP CCTV age test suite (<https://github.com/C2SP/CCTV/tree/main/age>),
available under 0BSD, CC0 1.0 or the Unlicense. `age_tests` checks every file in
this folder; vectors using zlib compression, ASCII armor, scrypt or post-quantum
identities are not included.
